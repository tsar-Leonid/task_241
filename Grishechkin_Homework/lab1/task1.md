# Task1

## 1) Переместиться между директориями
**используется команда cd (от англ. «change directory» — «сменить каталог»)**

## 2) Вывести список файлов в директории
**для  вывода списка файлов в директории (каталоге) используется команда ls . ls -l – это подробный список с дополнительной информацией, ls -a – показывает и скрытые файлы, начинается с точки(ссылка на текущую директорию), две точки – ссылка на родительскую директорию.**

## 3) Вывести список Всех файлов в директории
**find . – показывает все файлы и папки в текущей директории и её поддиректориях**

## 4) Создание папки с подпапками
mkdir f1/sub1 f1/sub2

## 5) Внутри папки создать файлик и записать в него что-нибудь
echo "Hello!" > f1/file1.txt
**Оператор > в Linux — оператор перенаправления, который перезаписывает файл.**

## 6) Переместить файл из одной директории в другую
**В Linux для перемещения файла из одной директории в другую используется команда mv (от «move»)**
mv f1/file1.txt f2/

## 7) Скопировать файл из одной директории в другую
**Для копирования файлов и директорий с сохранением исходных используется команда cp**
cp f2/file1.txt f1/copy.txt
**Опция -r необходима для рекурсивного копирования директорий. -p сохраняет атрибуты файла.**

## 8) Переименовать файл
mv 1.txt new_name.txt
**В Linux переименование - это частный случай перемещения файла в ту же директорию с новым именем.**

## 9) Сравнить содержимое файла
diff new_name.txt f1/copy.txt
**0a1**
**> Hello!**
**Чтобы сделать файлы одинаковыми, нужно в файл new_name.txt добавить строку "Hello!" на позицию 1**
**•	0a1 = "После строки 0 в первом файле добавь строку 1 из второго файла"**
**•	> Hello! = "Вот эта строка: 'Hello!'"**

## 10) Отсортировать содержимое файла по возрастанию и убыванию
**Сначала создал файл с неотсортированными данными**
cat > unsorted.txt << EEE
> banana
> apple
> date
> count
> lol
> EEE
# Затем сортировал, sort - cортировка по возрастанию (алфавитный порядок), sort -r – сортировка по убыванию
sort unsorted.txt
# apple
# banana
# count
# date
# lol

sort -r unsorted.txt
# lol
# date
# count
# banana
# apple

## 11) Удалить все папки и файлы
**Переходим в директорию выше cd ..**
**И удаляем с помощью rm -rf my_files - означает, что файлы и каталоги в указанном пути удаляются рекурсивно (удаляются каталоги и их содержимое) и принудительно (без запроса на подтверждение).**
