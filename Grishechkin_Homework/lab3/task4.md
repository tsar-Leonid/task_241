**1. Raid массивы, что такое и какие бывают**

**RAID (Redundant Array of Independent Disks)** — технология объединения нескольких физических дисков в единый логический массив для повышения производительности, надёжности хранения данных или их сочетания

**RAID 0 (чередование)** - Повышает производительность за счёт распределения данных между несколькими дисками. Отказоустойчивость отсутствует — выход из строя одного диска приводит к потере всех данных

**RAID 1 (зеркалирование)** - Обеспечивает надёжность путём полного дублирования данных на каждом диске массива. При отказе одного диска данные сохраняются

**RAID 5** - Сочетает производительность и отказоустойчивость за счёт распределения данных и контрольных сумм по всем дискам массива. Требует минимум трёх дисков и допускает отказ одного диска

**RAID 10 (1+0)** - Объединяет зеркалирование и чередование, обеспечивая высокую производительность и надёжность. Требует минимум четырёх дисков

**6. В чём между ними разница?**

RAID 0 ориентирован на производительность и не обеспечивает защиту данных

RAID 1 ориентирован на надёжность и сохраняет данные при отказе одного диска, но имеет меньший полезный объём (полезный объём — это та часть памяти или дискового пространства, которую реально можно использовать для хранения данных)

**7. Есть ли файловые системы которые поддерживают raid массивы без стороненго ПО**

Да, существуют файловые системы со встроенной поддержкой RAID:

**Btrfs (B-tree File System)** - поддерживает встроенные уровни RAID: 0, 1, 10, 5, 6

**ZFS (Zettabyte File System)** - поддерживает RAID-Z (аналог RAID 5), RAID-Z2, RAID-Z3; управление данными, зеркалирование и контроль целостности встроены в файловую систему

**LVM (Logical Volume Manager) + обычная файловая система** - можно создать аналог RAID через LVM-зеркалирование. Затем поверх создать ext4/xfs файловую систему

**8. Можно ли создать raid массив во время установки системы?**

Да, во время установки системы ALT Linux можно создать RAID-массив. Программа установки поддерживает создание программных RAID-массивов разных типов: RAID 1, RAID 0, RAID 4/5/6, RAID 10
