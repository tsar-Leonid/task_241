**1. Какая структура каталогов в linux? выведите список файлов в корне системы**

Структура файловой иерархии Linux, также известная как Filesystem Hierarchy Standard (FHS), определяет организацию каталогов и их содержимое в операционных системах, подобных Unix. 
- Согласно FHS, все файлы и каталоги располагаются внутри корневого каталога /, даже если физически или виртуально они находятся на разных устройствах.
- Некоторые из этих каталогов присутствуют в системе только при наличии определённых подсистем, например X Window System.
- Большинство из этих каталогов встречаются во всех UNIX-подобных системах и используются примерно одинаково.

**5. ЧТо за папки /bin,/sbin,usr/sbin,/usr/sbin**

- /bin - основные команды для всех пользователей
- /sbin - команды для администратора
- /usr/bin - дополнительные программы для пользователей(исполняемые файлы дополнительных программ для всех учётных записей)
- /usr/sbin - Дополнительные системные утилиты для админа. Содержит бинарные файлы для системных администраторов. Если нужной утилиты нет в /sbin, она может быть здесь. Примеры: atd, cron, sshd, useradd, userdel.
